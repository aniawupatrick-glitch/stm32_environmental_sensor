# STM32 Environmental Monitoring PCB Design

## Overview

This project involved designing a printed circuit board (PCB) for an STM32-based environmental monitoring system during my internship at Zaptek. The system was intended to interface with environmental sensors and a display.

## Design Objectives

- Design a PCB for an STM32-based environmental monitoring system.
- Provide hardware connections for temperature, humidity and light sensors.
- Incorporate the required connections for a display.
- Organise components and connections into a practical PCB layout.

## My Contribution

My role focused on PCB design using **KiCad**. This repository will document the hardware design work I am authorised to share from the internship.
